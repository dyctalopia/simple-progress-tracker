# Project Timeline

> Purpose: Single source of truth for `index.html`, synced via `sync-progress.py`

## Format

```
[*] Phase name    startDate: M/D    endDate: M/D
```

- `[*]` = current phase, `[ ]` = upcoming
- Dates in `M/D` format, year inferred from current year

## Phases

```
[*] Phase 1    startDate: 5/22    endDate: 5/23
[ ] Phase 2    startDate: 5/28    endDate: 6/15
```
